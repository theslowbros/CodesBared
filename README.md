# CodesBared

A browser-based QR code and barcode generator. Open `index.html` locally — QR codes render entirely in your browser with no network calls.

## Formats

- **QR Code** — fully offline, no dependencies
- **Code 128**, **EAN-13**, **UPC-A**, **Code 39**, **ITF-14**, **Codabar** — via JsBarcode from cdnjs

## Features

- Custom size, colors, and quiet-zone / whitespace
- Contrast check with a one-click boost for scannability
- Optional logo overlay on QR codes
- PNG and SVG download
